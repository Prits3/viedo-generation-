# Vercel release checks

Use a deployment Preview before merging to `main`. The project-level settings can differ even when `learnlayla.xyz` and `viedo-generation.vercel.app` build the same commit. Check each project separately if both are public.

1. **PDF sources:** The build log should show `pdf.js worker copied to public/pdf.worker.min.mjs`. `vercel.json` explicitly runs the asset script and then the build, even when the build environment skips npm lifecycle hooks. In the Preview, confirm `/pdf.worker.min.mjs` serves JavaScript, then open **Try an example → Central versus Southern Europe → 8–12 K** and confirm the PDF highlights the quote on page 1.
2. **Waitlist:** Set `NEXT_PUBLIC_SUPABASE_URL` and `NEXT_PUBLIC_SUPABASE_PUBLISHABLE_KEY` in the intended Vercel project's Preview environment and redeploy. These browser variables are baked into the build. Use a Supabase publishable key, never a secret or service-role key. In the preview Supabase project, confirm `public.waitlist` has a unique `email` and allows anonymous inserts but not reads or updates. Submit the same approved test address twice; both responses should confirm success, the dashboard should show exactly one row, and the original consent should be unchanged. Publishable-key configuration does not create user accounts.
3. **Live generation:** For a controlled Preview, set one provider variable in Vercel (`AWS_BEARER_TOKEN_BEDROCK` or `ANTHROPIC_API_KEY`) with the provider's spending limit in place. `/api/generate` should list that provider as configured; then generate once from a non-sensitive sample and verify the resulting lesson. Vercel's temporary filesystem does not provide a permanent library, and this deployment does not render new MP4 exports.
4. **FastAPI and accounts:** Deploy the service from [`deploy/backend`](../deploy/backend) to a host with a persistent volume for SQLite and its worker, then verify the backend's HTTPS `/health`. Wire the required application routes and account UI in a separate PR and test them in Preview. The current Next.js app has no `/backend/*` proxy on `main`; setting a backend URL alone will not connect it. Keep the public model-backed endpoints behind appropriate abuse and cost controls.

If a Preview fails, fix it before promoting. Never copy provider or database credentials into GitHub, chat or build output.
