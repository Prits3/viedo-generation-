LearnLayla (PaperScenes): drop a PDF, Word, PowerPoint or text file and get a narrated short or lesson
in which every statement links to its passage in the source. Code: https://github.com/trungminhdo4-glitch/viedo-generation-

Generated lessons on this Space are temporary (the disk is reset on restart). Uploaded documents are
sent to the model provider (Amazon Bedrock) to write the script.
